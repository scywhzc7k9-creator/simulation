# Terminal de Entrenamiento — Aeropuerto Internacional Valset

Página estática lista para GitHub Pages.

## Estructura

- `index.html`
- `assets/valset-logo.jpg`
- `.nojekyll`

## Publicación

1. Sube todos los archivos y la carpeta `assets` a la raíz del repositorio.
2. En GitHub abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**.
4. Elige `main` y `/ (root)`.
5. Guarda y espera el despliegue.

El popup de bienvenida aparece cada vez que se carga la página.
